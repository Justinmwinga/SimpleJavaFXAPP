# ICT261 Lab 1 — Simple JavaFX Application

A simple JavaFX application developed for **ICT261 Object-Oriented Programming & Java**.

The project demonstrates the basic setup and use of **Java 21, Gradle, JavaFX, Git, and GitHub**.

## Technologies Used

- Java 21
- JavaFX 21.0.12
- Gradle
- Git
- GitHub
- IntelliJ IDEA

## Project Features

The application demonstrates:

- A JavaFX application window
- A welcome message
- A Start button
- A Reset button
- Button event handling
- JavaFX layout management using `VBox`
- A customized application window title
- Gradle-based project execution
